# DOC-OCIM-Data

Data accompanying a research manuscript submitted to *Nature Communications*, including machine-learning reconstructed dissolved organic carbon (DOC) concentrations, ocean circulation inverse model (OCIM) outputs, and figure source data.

## Data contents

- **ML_product/**: Global three-dimensional machine-learning reconstructed DOC climatology (NetCDF).
- **OCIM_output/**: Three-dimensional DOC and oxygen diagnostic outputs from OCIM model (NetCDF).
- **Source_data/**: Source data for all main-text and supplementary figures (Excel).

## Data availability

The dataset is publicly archived on Zenodo:
